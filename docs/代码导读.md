## C# 与 Java 的关键差异（注释里都标出了）

### 1. 属性（Property）—— 最重要的差异

```csharp
public string Id { get; }        // 只读属性
```

调用时写 `gene.Id`，**不带括号**。

Java 等价写法：
```java
private final String id;
public String getId() { return id; }
```

### 2. struct（结构体）—— Java 没有

```csharp
public readonly struct Vec2 : IEquatable<Vec2>
```

值类型，赋值时**复制整份数据**：

```csharp
Vec2 a = new Vec2(1, 2);
Vec2 b = a;           // b 是独立副本
b = new Vec2(9, 9);   // a 仍然是 (1,2)
```

Java 的 class 是引用类型，`b = a` 会让两者指向同一对象。

### 3. 运算符重载 —— Java 没有

```csharp
public static Vec2 operator +(Vec2 a, Vec2 b) => new Vec2(a.X + b.X, a.Y + b.Y);
```

所以能写 `a + b`，而不是 `a.add(b)`。

### 4. 表达式体（`=>`）

```csharp
public double Length => Math.Sqrt(X * X + Y * Y);
public static double Dot(Vec2 a, Vec2 b) => a.X * b.X + a.Y * b.Y;
```

等价于 `{ return ...; }`。

### 5. out 参数

```csharp
DMath.SinCos(radians, out double s, out double c);
// 现在 s 和 c 都有值了
```

Java 得返回对象或用数组。

### 6. 空值运算符

```csharp
name ?? "默认值"              // null 就用默认值
_schema ??= CreateSchema();   // null 才赋值
Actor?.Motor?.State           // 任一环为 null 就返回 null
```

### 7. switch 表达式

```csharp
Duration = style switch
{
    ActionStyle.Roar => 1.7,
    ActionStyle.Slam => 1.15,
    _ => 0.9,
};
```

返回一个值，可直接赋值。

### 8. 模式匹配

```csharp
if (Follow is CreatureActor ca)    // 是的话绑定到 ca
```

Java 16+ 的 `instanceof` 模式几乎一样。

### 9. 特性（Attribute）

```csharp
[MethodImpl(MethodImplOptions.AggressiveInlining)]
[CreatureExtension]
```

用方括号，对应 Java 的 `@Annotation`。

## 速查表

| Java | C# |
|---|---|
| `getX()` | `X { get; }` |
| `record` | `readonly struct` |
| `a.add(b)` | `a + b` |
| `->` (lambda) | `=>` |
| `instanceof T t` | `obj is T t` |
| `switch` 语句 | `switch` 表达式 |
| `Optional.orElse` | `??` |
| `@Annotation` | `[Attribute]` |
| `final` 字段 | `{ get; }` 或 `readonly` |
| `enum.ordinal()` | `(int)enumValue` |

## 项目的核心概念

### 数据流

```
种子 ──► 基因组（基因值 + 4 个种子） ──► 骨架/颜色/花纹/动作 ──► 像素
```

每个阶段都是**纯函数**：给定相同输入必然得到相同输出。

### 四路独立种子

基因组带四个种子（结构/颜色/花纹/动作），所以：

- 改颜色**不会**改变体型
- 重掷花纹**不会**改变颜色
- 缓存能精确失效（只重建受影响的部分）

见 [CreatureGenome.DeriveStreamSeeds](../addons/procedural_creatures/Core/Genetics/CreatureGenome.cs)。

### 不可变对象

要改基因就创建新对象：

```csharp
var g2 = g1.With("size", 0.8);   // g1 不变
```

好处：线程安全、撤销简单、缓存友好。

### 坐标系

- **+X = 东**（屏幕右）
- **+Y = 上**（世界高度）
- **+Z = 南**（朝向观察者）

相机从北向南俯视，仰角 30°。见 [PixelCamera.cs](../addons/procedural_creatures/Core/Rendering/PixelCamera.cs)。

## 运行与验证

```powershell
# 运行工坊
Start.cmd

# 编译
dotnet build ProceduralPixelCreatures.sln

# 自测（28 项）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1
```

在 VS Code 里可用 `Ctrl+Shift+B` 编译、`Ctrl+Shift+P` → `Run Task` 运行。

## 注意

本机的 `%TEMP%` 和 `%APPDATA%\Godot` 受沙箱限制，所以：

- 编译需要 `NUGET_SCRATCH` 指向可写目录（VS Code 配置已设好）
- 启动 Godot 需要 `--log-file` 参数（`Start.cmd` 已处理）

如果手动调用 `dotnet build` 报 `Failed to load NuGet settings`，就是这个原因。
